Set up

Use the skills in your tool

The skills are plain folders of instructions in the open Agent Skills format, plus a small drawing engine and a few Python scripts. Most AI tools can now read them. Pick the row that matches how you work.

You useWhat to installWhat you get
A coding agent on your computerThe seven skill folders, copied by one commandThe full workflow: plan, build, a check at phone and laptop sizes, GIF and video recording
A chat app that supports skillsOne combined skill, visual-explainers.zipPlan and build; the check runs only where the app can install a browser
Any other chatbotOne file, visual-explainers-for-chat.md, attached to the chatPlan and build; you view the result in the chat's preview or the player page

Folder locations and menu names below come from each tool's documentation, checked on 24 November 2026. Tools change these often; if a path does not work, search the tool's docs for "skills".

Get the files

For a coding agent, clone the repository and run the installer with your tool's name. It copies the seven skill folders to the place that tool reads, for every project, or for one project with --project.

git clone https://github.com/k-sandhu/visual-explainer-skills
cd visual-explainer-skills
python scripts/install.py codex
# tools: agents, antigravity, claude-code, codex, copilot, cursor, gemini-cli, opencode
python scripts/install.py cursor --project ~/my-app   # one project only

Without Python, copy the seven folders inside skills/ into the folder listed for your tool below.

For the checks and recordings

The explainers themselves need nothing. The page check and the GIF recorder need Python 3.10 or later and a headless browser:

pip install playwright pillow
playwright install chromium
# optional, for GIF and MP4: ffmpeg on your PATH

Without them the agent can still build an explainer, and the skills tell it to say which checks it skipped.

For chat apps

Download from the latest release: visual-explainers.zip (one skill to upload) and visual-explainers-for-chat.md (one file to attach to any chat).

Coding agents

Coding agents on your computer

Each of these reads skill folders natively. After installing, start a new session and ask in plain words; the agent reads the skill descriptions and loads them when your request fits. The tools are listed alphabetically.

Claude Code

Install as a plugin from inside a session:

/plugin marketplace add k-sandhu/visual-explainer-skills
/plugin install visual-explainers@visual-explainer-skills

Or run python scripts/install.py claude-code, which copies the folders to ~/.claude/skills/ (one project: .claude/skills/).

To call one by name, type /explainer-director (or /visual-explainers:explainer-director when installed as a plugin).

Codex (CLI, IDE extension and app)

Run python scripts/install.py codex. It copies the folders to ~/.agents/skills/ (one project: .agents/skills/).

Ask in plain words, list skills with /skills, or name one with $explainer-director.

Codex's default sandbox has no network access, so install Playwright and Chromium before you start a session, or approve the install when Codex asks.

Cursor

Version 2.4 or later. Run python scripts/install.py cursor, which copies the folders to ~/.cursor/skills/ (one project: .cursor/skills/). Cursor also reads ~/.claude/skills/ and ~/.agents/skills/, so one copy for another tool may already be enough.

Ask in Agent mode, or pick a skill from the / menu.

Gemini CLI and Antigravity CLI

Gemini CLI reads skills by default in recent versions (0.26 and later; older ones need skills.enabled turned on). Run python scripts/install.py gemini-cli (folder ~/.gemini/skills/), then check with /skills list. Gemini CLI asks for your consent the first time it activates a skill.

Google moved free-tier and Google One users from Gemini CLI to Antigravity CLI in June 2026. For Antigravity, run python scripts/install.py antigravity (folder ~/.gemini/config/skills/; one project: .agents/skills/).

GitHub Copilot in VS Code

VS Code 1.109 or later, in agent mode. Run python scripts/install.py copilot (folder ~/.copilot/skills/), or, to share the skills with everyone on a repository, python scripts/install.py copilot --project ., which uses .github/skills/.

Copilot asks before it runs terminal commands such as the page check; approve them, or the explainer is built without being checked.

OpenCode

Run python scripts/install.py opencode (folder ~/.config/opencode/skills/; one project: .opencode/skills/). OpenCode also reads ~/.claude/skills/ and ~/.agents/skills/.

Allow the skill, edit and bash permissions in opencode.json, or approve them when asked. OpenCode works with open-weight models; see which model.

Other tools that read Agent Skills from ~/.agents/skills/ work the same way: python scripts/install.py agents.

Chat apps

Chat apps in the browser

Chat apps run the assistant on the provider's servers, so there is nothing to install on your computer. Two routes:

Upload a skill

Where the app supports skills, upload visual-explainers.zip once. It then loads by itself when you ask for an explainer, in every chat.

Attach one file

Anywhere else, attach visual-explainers-for-chat.md to the chat (or to a project, so every chat in it has it) and ask. The chatbot writes one HTML page that loads the engine from a public link.

To see the result: open the chat's preview of the HTML code if it has one. If it does not, or the preview blocks the engine's link, copy the code into the player page, which runs it and saves a single file that works offline.

ChatGPT

Skills (Business, Enterprise, Edu and Healthcare plans)

Open Plugins, then the Skills tab, then Create, and upload visual-explainers.zip. Your admin may need to allow skills first. Uploads are scanned and may show "Needs review" for a while.

Any plan

Attach visual-explainers-for-chat.md to a chat or a project and ask for an explainer. Code blocks have a Preview button that renders the page.

ChatGPT's Python tool has no internet access, so the page check cannot install its browser there; expect the explainer without the automatic check.

Claude (web and desktop apps)

Turn on Settings, Capabilities, "Code execution and file creation". Then open Customize, Skills, the plus button, "Upload a skill", and choose visual-explainers.zip. On Team and Enterprise plans an owner may need to allow skills first.

Or attach visual-explainers-for-chat.md to a chat or a project.

The app's descriptions are limited to 200 characters, which is why the uploadable zips carry short versions.

Gemini app

Personal Google accounts: open Customize, Skills, Create, and upload visual-explainers.zip. Up to 100 skills can be on at once. Work and school accounts are due to get skills in 2027; until then, attach the chat file.

Canvas does not work together with skills, so view the result through the code preview or the player page.

Other chatbots

Any chatbot that accepts a file or a long system prompt can use visual-explainers-for-chat.md: Le Chat, Microsoft Copilot, or an open-weight model in a local app such as LM Studio or Open WebUI. The file is about 84 KB (roughly 22,000 tokens), so the model needs a context window of at least 64,000 tokens to leave room for the data and its answer.

Models

Which model

Any model that can write a long, careful program can follow the skills. To check that the instructions work outside the tool they were written in, the same request went to five setups on 24 November 2026: a bakery's 60 orders, half taken at the counter and half through a new app, and "make an interactive explainer that helps the staff see whether the app cut waiting times". The data was made up for the test, so the right answers are known exactly: the app's average wait was 0.28 minutes shorter (8.48 against 8.76), its middle wait 1.35 minutes shorter, and the four slowest of all 60 orders came through the app. With 30 orders a side, the data cannot tell whether the app really helps.

Seven steps with the right averages on screen, but the answer options in its guess step came from its own mental arithmetic (a 2-second gap instead of 17 seconds). The first try, capped at 32,000 output tokens, spent all of them thinking and returned nothing.

One run per setup, so this shows that each setup can work, not how often it does. The runs found a bug in the engine (a start-button label that broke lessons with an opening), fixed in version 0.7.0. Three runs hit it: two worked around it themselves and one left the error in the page. Codex's newest models were refused by the installed command-line version, so GPT-6.1 Sol stands in for them.

What this suggests

  • A small model can do it when it can run the checks: the small closed model needed many more turns but finished with a correct page.
  • Without tools, a model cannot run the numbers it writes into prose or answer options. Ask it to compute every number in the page's code, and read the guess and summary steps against your data.
  • Reasoning models in a plain chat can spend their whole output budget thinking. If a reply comes back empty or cut off, ask again or raise the limit.

Asking for an explainer

Say what the data is, what you want people to understand and who will look at it, and where. You do not need to name a form or a skill.

data.csv has 60 orders from our bakery, half taken at the counter and half through the new app, with how long
each customer waited. Make an interactive explainer for the staff meeting that shows whether the app cut
waiting times. They will look at it on laptops.
  • Give the data as a file, or paste it. Every number on screen is computed from it.
  • Say who the reader is and what they already know. The opening is written for them.
  • Say where it will be seen: a page, a slide, a report, or a social post (which gets a self-playing card).
  • Ask for a GIF or video if you want one; coding agents with ffmpeg can record it.
