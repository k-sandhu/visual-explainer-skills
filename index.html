Open-source skills for AI assistants

Explainers that start where the reader is

Most charts are made for people who already know the subject. These instructions teach an AI assistant to do what a good teacher does instead: start with the situation in plain words, build the idea one step at a time, let the reader try something, and only then show the real numbers. The result is one interactive web page that works on a laptop or a phone.

How it works

You ask in plain words; the assistant plans, builds and checks

The skills are a set of instruction files plus a small drawing engine. Any AI assistant that can read files can follow them. You give it your data or a description and say who the explainer is for.

1

Plan before drawing

The assistant writes the one message in a sentence, decides what the reader does not know yet, writes the opening for a newcomer, picks one of six forms and storyboards one idea per step.

2

Build one file

A small engine handles the parts that are easy to get wrong: steps that never bleed into each other, controls that never move, colours that colour-blind readers can tell apart, and a layout for both laptops and phones.

3

Check it like a reader

Where the assistant can run code, a check opens the page at phone and laptop sizes, walks every step, presses every control and reports overlapping text, low contrast and stale numbers. It can also record a GIF or video.
