For chat apps

Run an explainer a chatbot wrote

If you use the chat file in a chatbot that cannot show HTML, or cannot load the explainer engine, paste its code here. The page runs it with the engine and can save a single HTML file that opens in any browser, offline, with nothing else to install.

  1. 1. CopyCopy the whole HTML code block from the chat, or only the part inside the last <script>.
  2. 2. Paste and runPaste it below and press Run. Errors show under the box.
  3. 3. SavePress Save to get one file you can share, put on a website or attach to an email.
